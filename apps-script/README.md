# 連接 Google Sheet（Apps Script）

網站透過一支綁在試算表上的 Apps Script 讀取行程，也把「行前清單」的勾選和「記帳」寫回試算表。試算表保持私人，只有這支程式能讀寫。

## 一次性設定（約 5 分鐘）

1. 打開「北越十日 2026 資料庫」試算表，選單 **擴充功能 → Apps Script**。
2. 把 [`Code.gs`](Code.gs) 的內容整個貼上，取代原本的 `myFunction`，按存檔。
3. 上方函式選單選 **setupFromWebsite**，按 **執行**。第一次會要求授權：選你的 Google 帳號 →「進階」→「前往（不安全）」→ 允許。
   這一步會從網站下載 `seed.json`，建立所有分頁、下拉選單、核取方塊和「預算總覽」公式。已經有資料時會先問你是否覆蓋。
4. 左側 **專案設定（齒輪）→ 指令碼屬性 → 新增指令碼屬性**：屬性 `WRITE_KEY`，值填你自己定的寫入密碼。
5. 右上 **部署 → 新增部署作業**：類型選「網頁應用程式」，執行身分選 **我**，誰可以存取選 **所有人**，按部署。
6. 複製「網頁應用程式網址」（結尾是 `/exec`）。
7. 打開網站 →「出發前」→「Google Sheet 同步」：貼上網址、填寫入密碼，按「測試寫入密碼」。

想讓每支手機都自動連上，把網址填進 repo 的 `config.js`（`sheetApi`）再推上 GitHub。網址可以公開，寫入密碼不要寫進任何檔案。

## 之後修改程式

改了 `Code.gs` 要重新部署才會生效：**部署 → 管理部署作業 → 編輯（鉛筆）→ 版本選「新版本」→ 部署**。網址不會變。

## API

| 方法 | 內容 |
| --- | --- |
| `GET <網址>` | 回傳 `{ ok, generated, tables }`，每張表是物件陣列，欄位名是英文代號、值是試算表上看到的文字 |
| `POST <網址>`，body 為 JSON 文字 `{ key, action, ... }` | `ping`；`check`（`id`, `done`）；`expense.add`（`expense`）；`expense.delete`（`id`） |

POST 請用 `Content-Type: text/plain`，瀏覽器才不會先送 CORS 預檢。

## 選單功能

試算表上方會多一個「北越十日」選單：

- **從網站匯入初始資料**：重建所有分頁（會覆蓋現有資料，執行前會確認）。
- **檢查資料**：找出重複代號、不存在的參照（例如時間軸指到不存在的地點）和不在選單裡的選項。
- **預覽網站讀到的資料筆數**。
