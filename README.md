# 北越十日 2026

2026/11/2–11/11 河內・沙壩・寧平 的個人旅行手冊。手機優先、可安裝的 PWA，資料放在 Google Sheet。

網站：https://zhonglunhuang.github.io/vietnam-trip-2026/

- **行程**：每天一張實景照片當封面，下方是時間軸。交通段用票根樣式，景點有大圖卡片，點開可以看開放時間、票價、地址，也能直接開 Google 地圖導航或出示越南文地址給司機。每一站的「要先知道」列出預約、開放時間、休館日、票價與要帶的東西。旅途中會自動跳到當天並標出下一站（App 從背景回來時也會更新）。
- **這天怎麼過**：前一兩天看狀況再決定的選項：狀況好就訂一日遊或活動（附最晚預訂時間與訂購連結），想休息就看附近的餐廳和按摩。
- **地圖**：依經緯度比例繪製的路線總覽與各區地點位置。
- **美食**：河內、沙壩、寧平的特色菜與店家（標示 2026 年米其林指南）、按摩店，菜名可以全螢幕給店家看。
- **預訂與花費**：訂位狀態、下一步與訂購連結、可以臨時訂的行程、住宿、記帳（寫回 Google Sheet）、預算估算。
- **出發前**：行前清單（同步到 Google Sheet）、匯率換算、注意事項、緊急聯絡、實用越南語、照片來源。
- **離線**：第一次開啟後，行程與照片都存在手機上，沙壩山區沒訊號也能看（Google 地圖連結仍需網路）。

每個項目都標示「已訂／待確認／待訂／建議」，查不到官方資料的標示「資訊未確認」。

## 資料流

```
Google Sheet ──(Apps Script 網頁應用程式)──> 網站
     ^                                         |
     └──── 行前清單勾選、記帳（POST）──────────┘
```

- 試算表的每個分頁就是一張資料表，欄位定義在 [`sheet.js`](sheet.js)，網站與工具共用。
- 沒設定 Google Sheet 時，網站用 [`data.js`](data.js) 的內建快照；設定之後改讀試算表，並把上次的內容存在手機。讀到的內容不能用（例如「每日」分頁是空的）時不會蓋掉上次的資料。
- Apps Script 的網址是公開的：只靠網址讀得到行程，讀不到記帳。記帳要在填了寫入密碼的手機上才會讀到（`POST expenses.list`）；沒有密碼的手機只顯示自己記的帳。
- 勾選和記帳先存在手機，有網路且有寫入密碼時再依序寫回，所以在山上沒訊號也能記帳。暫時寫不回去（試算表忙碌、訊號不好）會保留稍後再送；確定寫不進去的記帳會標成「寫回失敗」，可以按「重試」。

設定步驟見 [`apps-script/README.md`](apps-script/README.md)。

## 檔案

| 路徑 | 用途 |
| --- | --- |
| `index.html`、`styles.css`、`app.js` | 網站（無框架、無建置步驟） |
| `sheet.js` | 資料表與欄位定義、資料表轉成網站資料的轉換 |
| `data.js` | 內建資料快照 |
| `config.js` | 網站設定（Apps Script 網址） |
| `img/` | 景點與菜色照片（WebP，600 與 1200 寬） |
| `apps-script/Code.gs` | 試算表的 API 與「從網站匯入初始資料」 |
| `seed.json` | 匯入試算表用的初始資料 |
| `manifest.webmanifest`、`sw.js`、`icons/` | PWA 設定、離線快取、主畫面圖示 |
| `tools/pull_sheet.js` | 從試算表抓最新資料，更新 `data.js` 與 `seed.json`（會清掉記帳、行前清單的勾選與完成時間，這兩個檔案是公開的） |
| `tools/export_seed.js` | 由 `data.js` 產生 `seed.json`（`node tools/export_seed.js [輸出檔]`） |
| `tools/export_xlsx.py` | 把資料匯出成 .xlsx（手動上傳到 Drive 的替代做法，需要 openpyxl） |
| `tools/release.sh` | 發布前更新版本號 |

## 本機預覽

```bash
python3 -m http.server 8770
```

開啟 http://localhost:8770 。service worker 只在 `localhost` 或 https 下運作。

## 發布更新

```bash
sh tools/release.sh
```

這會重新產生 `seed.json`，並更新 `index.html` 的 `?v=` 與 `sw.js` 的 `VERSION`，再 commit、push 到 `main`，GitHub Pages 約 1 分鐘後更新。

照片來自 Wikimedia Commons，依各自的 CC0、公有領域、CC BY 或 CC BY-SA 授權使用，已縮放與裁切。每張照片的作品標題（取自 Commons 檔名）、作者、授權與原始頁面列在網站「出發前 → 照片來源」，也在試算表的「照片 photos」分頁。少數找不到原景點照片的項目改用同一地區的照片，說明文字有寫清楚。

- 資料查證日期：2026 年 10 月 25–26 日。票價、營業時間與班次可能變動，出發前請以官方網站或訂位平台為準。
- 本站不包含機票票號、訂位代碼、護照號碼或付款資訊。
- 「訂位」的訂購連結與「每日選項」的連結只接受 `https://` 或 `http://` 網址，一行一個，格式「標籤 | https://網址」。
