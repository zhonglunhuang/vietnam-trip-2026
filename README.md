# 北越十日 2026

2026/11/2–11/11 河內・沙壩・寧平 的個人旅行手冊，手機優先、可安裝的 PWA（漸進式網頁應用程式）。

- **行程**：每日時間軸，標示「已訂／待確認／待訂／建議／資訊未確認」，旅途中會自動跳到當天並標出「接下來」的行程
- **地圖**：依經緯度比例繪製的路線總覽、各區地點相對位置圖，每個地點都有 Google 地圖與導航連結，另有「給司機看」的越南文地址卡
- **美食**：河內、沙壩、寧平的特色菜與推薦店家，點菜卡可全螢幕給店家看
- **預訂**：訂位狀態與待辦、住宿資訊、可自填實際花費的預算表
- **準備**：行前清單（勾選狀態存在本機）、匯率換算、注意事項、緊急聯絡、實用越南語
- **離線**：第一次開啟後由 service worker 快取，沙壩山區訊號差時仍可瀏覽（Google 地圖連結仍需網路）

## 檔案結構

| 檔案 | 用途 |
| --- | --- |
| `index.html` | 頁面外殼 |
| `data.js` | 全部行程內容（修改行程只要改這個檔案） |
| `app.js` | 互動邏輯（無框架、無建置步驟） |
| `styles.css` | 樣式，含淺色與深色主題 |
| `manifest.webmanifest`、`sw.js`、`icons/` | PWA 設定、離線快取、主畫面圖示 |
| `tools/build_single.py` | 把所有檔案合併成單一 HTML（`dist/`） |

## 本機預覽

```bash
python3 -m http.server 8770
```

開啟 http://localhost:8770 。service worker 只在 `localhost` 或 https 下運作。

## 部署到 GitHub Pages

Repo 的 Settings → Pages → Source 選 `Deploy from a branch`，Branch 選 `main`、資料夾 `/ (root)`。完成後網址為 `https://<帳號>.github.io/<repo>/`，用手機開啟後即可「加入主畫面」。

更新內容後請同時修改 `sw.js` 裡的 `VERSION`，讓已安裝的手機抓到新版。
